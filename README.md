# Simple Interest Calculator

A simple Command Line Interface (CLI) application written in Bash to calculate simple interest based on user inputs.

## Description

This script calculates the simple interest using the standard mathematical formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual rate of interest
- **T** = Time period in years
